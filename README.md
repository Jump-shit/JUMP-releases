# JUMP Releases

JUMP is a free, local document editor and PDF reader for Apple Silicon Macs. The public beta runs in guest mode with no account required.

- [Official website](https://jump-editor.pages.dev/)
- [Installation and verification](INSTALL.md)
- [Public beta release notes / 公测版更新说明](RELEASE-NOTES.md)

The beta installer is pending release. Once available, obtain it from [GitHub Releases](https://github.com/Jump-shit/JUMP-releases/releases). Updates are manual.
