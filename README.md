# JUMP Releases

JUMP is a free, local document editor and PDF reader for Apple Silicon Macs and Windows 11 x64 PCs. The public beta runs in guest mode with no account required.

- [Official website](https://jump-editor.pages.dev/)
- [macOS installation and verification](INSTALL.md)
